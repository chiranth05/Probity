# Probity — Property Management & Liaisoning Consultancy

Probity is a static-site presentation for a Bengaluru-based property-management, liaisoning, and consultancy business, showcasing services offered, team contact information, and a portfolio of completed projects (Brookfield, DP World, Purva, and more).

## 🌐 Live Demo

Access the live site: **[probitybengaluru.in](https://probitybengaluru.in)**

## 🏢 What Probity Offers

Probity is built to present a professional consultancy front end with zero backend overhead, combining a polished visual experience with genuine SEO groundwork:

- **Immersive First Impression:** A full-screen animated intro film (`Probity-Logo-Animation2.mp4`) plays once per session, backed by a Three.js 3-D background animation for a distinctive landing experience.
- **Interactive Contact Card:** A custom-built "business-card" UI component slides over the page on click, giving visitors a tactile way to reach the team instead of a static footer.
- **Real Project Portfolio:** A lightweight gallery page (`gallery.html`) presents completed projects in a CSS grid, giving prospective clients tangible proof of work rather than vague service claims.
- **Search-Ready Out of the Box:** Open-Graph tags, Twitter Cards, and schema.org LocalBusiness JSON-LD are baked into the markup, so the site is discoverable without any additional SEO tooling.

## 🧠 Why It's Built This Way

Most small consultancy sites either ship as bloated CMS installs or bare-bones template pages. Probity avoids both:

- **No Framework Overhead:** No build step, no bundler, no package.json to maintain — just HTML, CSS, and vanilla JavaScript (ES2020). Anyone can clone it and edit the markup directly.
- **Fast by Default:** With zero runtime dependencies beyond a single Three.js bundle, the site loads fast even on the mobile connections most prospective clients will be browsing on.
- **Mobile-First from the Ground Up:** CSS custom properties and media queries drive a responsive layout, rather than retrofitting a desktop design.
